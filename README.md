# tuneidem

Tune CSV/TSV idem tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tuneidem/

## Install / run

```bash
git clone https://github.com/theworker02/tuneidem.git
cd tuneidem
node src/cli.js
node --test
```
